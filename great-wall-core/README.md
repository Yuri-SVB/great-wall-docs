# great-wall-core — design documents

**The Wall.** The fractal encoder engine: bit-exact encoding and decoding of
seed entropy onto a user-specific perturbation of the Burning Ship fractal,
in Rust with I4F60 fixed-point arithmetic and a Python FFI bridge.

Status: beta, public. Depends on nothing else in the ecosystem.
