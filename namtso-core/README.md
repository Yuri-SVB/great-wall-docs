# namtso-core — design documents

**Timechain-derived salt primitive.** Derives a public, memorization-free,
precomputation-resistant salt from the Bitcoin timechain.

Status: in development. Depends on nothing else in the ecosystem.

Its specification lives with the architecture rather than here:

| Document | Covers |
|---|---|
| [`../great-wallet/ARCHITECTURE.md`](../great-wallet/ARCHITECTURE.md) §7 | Responsibilities and the derivation |

> [!NOTE]
> The architecture calls this component `namtso-core`; the repository is
> `namtso-the-sacred-salt`, and `great-wallet` carries it under the latter
> path. The two names refer to the same component.

Implementation: [github.com/Yuri-SVB/namtso-the-sacred-salt](https://github.com/Yuri-SVB/namtso-the-sacred-salt)
