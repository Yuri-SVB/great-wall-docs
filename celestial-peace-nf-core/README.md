# celestial-peace-nf-core — design documents

**Celestial Peace: Never Forget (CPNF).** The spaced-repetition memory engine
that consolidates a user's tacit recall of a fractal setup, so the knowledge the
protocol depends on survives without ever being written down.

Status: in development — Step 1 (scheduler core) implemented. Imports
`great-wall-core` and `star-clock`.
