# Feedback Instruments

Templates for the three feedback layers described in
[`../methodology.md`](../methodology.md). Copy each into your survey tool of
choice (Google Forms, Tally, Framaforms, a Discord bot — anything with CSV
export). They are written tool-agnostic and Markdown-plain so they version with
the rest of the course.

Design rules for every form:

- **Short beats thorough.** Completion rate is the metric. If a form takes more
  than ~5 minutes, cut questions.
- **Confidence before/after, not just "was it clear?"** Self-reported
  confidence on the *specific* session outcomes is more actionable and less
  flattery-prone than a satisfaction score.
- **Always one fully open question.** The unprompted comment is where the real
  signal hides.
- **Anonymous by default**, with an optional handle field so we can follow up on
  a great comment.

Files:

- [`pre-course-survey.md`](./pre-course-survey.md) — once, before Session 1.
- [`per-session-form.md`](./per-session-form.md) — after every session
  (parameterized by session #).
- [`post-course-survey.md`](./post-course-survey.md) — once, after Session 5.

Scales: use a **1–5** Likert throughout (1 = not at all / strongly disagree,
5 = completely / strongly agree) so results are comparable across forms.
